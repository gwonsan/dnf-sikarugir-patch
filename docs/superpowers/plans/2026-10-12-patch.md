# DNF Sikarugir Patch Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Package the verified Neople URL bridge and Korean font mappings as a reversible installer, then publish to a new private GitHub repository.

**Architecture:** A Swift application forwards URLs to the selected existing Sikarugir wrapper. The same executable installs the bridge, snapshots only affected font values, applies Korean aliases, and restores them on uninstall. A universal release contains double-click install and uninstall commands.

**Tech Stack:** Swift, AppKit, Foundation, CoreServices, shell; existing Sikarugir Wine and Winetricks.

**Spec:** This document records the user's requested packaging of the working repair, with a private GitHub destination.

## Global Constraints

- macOS 14.6 or newer; Wine 11 layout verified on Apple Silicon with Rosetta.
- Preserve every URL as one argument; reject other schemes and control characters.
- Never include authenticated URLs, logs, personal paths, game files, Wine binaries, or third-party icons in the repository.
- Keep original wrapper settings and running downloads intact.
- Report launcher download verification separately from unverified game play.

## Review Focus

- Wrapper paths containing spaces must work.
- Reinstallation must preserve the first backup.
- Uninstall must preserve font aliases changed after installation.
- A failed installation must retain a usable restore state.
- Existing applications at the install destination must not be overwritten without ownership evidence.
