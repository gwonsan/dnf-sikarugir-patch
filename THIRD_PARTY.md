# Third-party components in the ready package

The patch's own code is MIT licensed. This does not relicense bundled components.

- Official Template 1.0.21: https://github.com/Sikarugir-App/Template/releases/tag/v1.0. Configure sources: https://github.com/Sikarugir-App/Sikarugir-foss-sources.
- D3DMetal and other renderers are the unmodified template components. Their licenses and acknowledgements remain inside DNF.app. The included Apple Game Porting Toolkit agreement permits distribution only for noncommercial purposes (sections 2A and 2C); this free private package is not a commercial game port. See `Contents/Frameworks/renderer/d3dmetal/License.rtf` and `Acknowledgements.rtf`.
- Source Han Sans 2.004: https://github.com/adobe-fonts/source-han-sans/releases/tag/2.004R. The unchanged font is under SIL Open Font License 1.1; the full license accompanies it at `Contents/Resources/DNF-Licenses/SourceHanSans-OFL.txt`.
- NeopleCustomURLStarter.exe and NeopleInstallerStarter.exe: installed from the official NeopleCustomURLBuilder.exe obtained at https://df.nexon.com/data/client. These remain Neople's proprietary software and are included for the requested personal/private setup. Game content and the logged-in launcher's runtime files are excluded.
- WS12WineSikarugir11.0_1 is downloaded from the official engine release during installation, not included in the ready ZIP. Engine releases: https://github.com/Sikarugir-App/Engines/releases/tag/v1.0; Wine source: https://github.com/Sikarugir-App/wine.

Installing Rosetta requires Apple's license agreement. The start command invokes the interactive official installer when needed and does not automatically accept its terms. Safari authentication remains in Safari; no browser session, user prefix, game files or launcher logs are included in the distribution.
